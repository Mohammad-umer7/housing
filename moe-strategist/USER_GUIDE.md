# MOE Strategist - User Guide

## Getting Started

### Accessing the Platform

1. **Sign In Page**: The first screen you'll see is the Sign In page with two options:
   - **User Account**: Standard access to dashboards and reports
   - **Admin Account**: Full access including user management

2. **Demo Mode**: You can use any email/password combination to explore the platform

### Main Dashboard Areas

## 🎯 Command Center

The heart of the platform, designed for rapid decision-making.

### Key Components:

#### Intelligent Search Bar
- **Location**: Center of the screen
- **Function**: Accept natural language queries
- **Examples**:
  - "Compare the energy sustainability metrics of the UAE and Norway"
  - "What are the infrastructure trends in Southeast Asia?"
  - "Show me bilateral trade growth in 2026"
- **AI Thinking Process**: Watch the AI work through multiple steps:
  - Fetching latest infrastructure data
  - Analyzing energy production metrics
  - Synthesizing bilateral agreements
  - Processing sustainability indicators
  - Compiling comprehensive report

#### KPI Snapshots (Critical Indicators)
- **Global GDP Growth**: Year-over-year economic growth metrics
- **Energy Production**: Real-time renewable energy output
- **Sustainability Index**: Environmental performance metrics
- **Infrastructure Rating**: Global infrastructure development score

Each KPI card shows:
- Current value with unit
- Percentage change indicator (up/down arrow with color coding)
- Trend description
- Interactive hover effects for detailed view

#### Executive Action Bar
Quick-access buttons for:
- **Generate Briefing Deck**: Create executive presentation
- **Create Summary Report**: Generate detailed analysis
- **Generate Visual Insight**: Produce visual analytics

## 🔄 Comparison View

Compare two countries across multiple metrics.

### How to Use:

1. **Select Countries**: Use dropdown menus to choose two countries
   - Available: UAE, Norway, Germany, Singapore, Canada, Australia, Japan, USA, China, India, Brazil, France

2. **Choose Metrics**: Toggle which metrics to compare
   - Energy Production
   - Sustainability
   - Transport Infrastructure
   - GDP Growth

3. **View Visualizations**:
   - **Line Chart**: Track trends over time
   - **Radar Chart**: See comprehensive metric comparisons
   - **Bar Chart**: Compare individual metrics side-by-side

### Tips:
- Select 2-4 metrics for clearest comparison
- Trends update automatically when you change selections
- Hover over chart data points for exact values

## 💡 Pro Tips

1. **Natural Language Searching**: Be specific but conversational
   - ✓ Good: "Which countries have the highest renewable energy adoption?"
   - ✗ Bad: "energy renewable"

2. **Comparison Analysis**: Focus on 2-3 metrics for clarity
   - Too many charts make patterns hard to spot
   - Start broad, then dive into specific metrics

3. **Report Generation**: Use for different audiences
   - Briefing Deck: Executive meetings
   - Summary Report: Policy recommendations
   - Visual Insight: Public presentations

4. **Data Interpretation**:
   - Green indicators = Positive change
   - Red indicators = Negative change
   - Check timestamps for data freshness

5. **Share Responsibly**: 
   - Download reports for offline sharing
   - Use appropriate export format for audience
   - Check data classifications before sharing

## 🐛 Troubleshooting

### Search Not Working
- Ensure internet connection is active
- Try more specific queries
- Check if data loading indicator is visible

### Charts Not Loading
- Refresh the page
- Try selecting different metrics
- Clear browser cache

### Export Issues
- Ensure PDF reader is installed
- Check browser download settings
- Try different export format
