## How to capture

1. Run the app (`npm run dev`) and log in
2. Use your OS screenshot tool (Win+Shift+S on Windows) to grab each screen
3. Save with the exact filenames above into this folder
4. Aim for a consistent browser width (~1280px) so they look uniform in the README

Keep them under ~500KB each (PNG, or compress via tinypng.com) so the repo stays light.
